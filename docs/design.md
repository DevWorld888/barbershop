---

# Brand Personality

The brand should feel:

* premium
* masculine
* stylish
* welcoming
* modern
* detail-oriented

The experience should communicate:
"More than a haircut, a confidence upgrade."

---

# Color Palette

Primary:

* Black
* Charcoal
* White

Accent:

* Metallic silver

Avoid:

* bright random colors
* too many gradients
* cluttered UI

---

# Typography

Style:

* bold headings
* clean readable body text
* modern masculine feel

Headings:

* strong
* large
* high contrast

Body text:

* simple
* readable
* concise

---

# Layout Style

* large hero section
* full-width sections
* generous spacing
* premium card layouts
* dark aesthetic
* mobile-first

# Images

Use:

* real haircut photos
* premium barber environment
* close-up grooming shots

Avoid:

* generic stock photos
* low-quality images

---

# UI Feel

The website should feel:

* fast
* premium
* professional
* clean
* easy to navigate

Not:

* flashy
* overcrowded
* overly animated
