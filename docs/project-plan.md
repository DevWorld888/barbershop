# Project Plan

## Project

Diego’s Barbershop landing page for Hobart, Tasmania.

## Main Goal

Create a premium local barbershop website that converts visitors into online bookings.

---

# MVP Scope

Build a one-page landing page with:

1. Navbar
2. Hero section
3. Services section
4. Special offer section
5. Gallery section
6. Why choose us section
7. Reviews placeholder
8. Booking CTA
9. Location/contact section
10. Footer

---

# Phase 1: Foundation

Create:

* Next.js project
* Tailwind setup
* basic folder structure
* global styles
* reusable components
* project documentation

Do not create backend logic.

---

# Phase 2: Homepage

Build homepage sections:

* Hero
* Services
* Special offer
* Opening hours
* Gallery
* Reviews placeholder
* Booking CTA
* Footer

Focus:

* mobile-first
* clean layout
* premium dark design
* strong CTA
* fast loading

---

# Phase 3: SEO Setup

Add:

* metadata
* Open Graph metadata
* local keywords
* semantic headings
* LocalBusiness JSON-LD schema
* optimized image alt text

Target:

* barber Hobart
* barbershop Hobart
* men’s haircut Hobart
* fade haircut Hobart
* beard trim Hobart

---

# Phase 4: Booking Integration

Use external booking link first.

Options:

* Booksy
* Fresha
* Square Appointments

Do not build custom booking yet.

Add:

* Book Now buttons
* booking CTA section
* tracking-ready click events later

---

# Phase 5: Trust & Conversion

Add:

* real haircut photos
* client reviews
* Google Maps
* Instagram link
* WhatsApp/contact link
* special offer section

---

# Phase 6: Launch

Before launch:

* test mobile
* test desktop
* check SEO metadata
* check CTA buttons
* check page speed
* connect domain
* submit sitemap to Google Search Console
* connect Google Analytics

---

# Not Included Yet

Do not build:

* custom booking system
* login
* dashboard
* payments
* CRM
* admin panel
* database

These can be added later if the business validates demand.

---

# Future Expansion

Possible future features:

* dedicated service pages
* suburb SEO pages
* blog
* haircut gallery CMS
* WhatsApp reminders
* weekly earnings dashboard
* barber client CRM
* no-show tracking
* loyalty system
* AI assistant for customer replies

---

# Development Principle

Build simple first.

The first version should:

* look premium
* load fast
* rank locally
* get bookings
* be easy to maintain
