# Diego's Barbershop Website

## Project Goal

Build a premium, SEO-focused barbershop landing page for Hobart, Tasmania that converts visitors into online bookings.

The website must feel:

* premium
* masculine
* modern
* clean
* trustworthy

Main business goal:
Increase bookings and build local brand presence.

---

# Tech Stack

* Next.js App Router
* TypeScript
* Tailwind CSS
* Vercel deployment

---

# Technical Rules

* Use semantic HTML.
* Use Server Components by default.
* Use Client Components only when necessary.
* Avoid unnecessary libraries.
* Avoid overengineering.
* Avoid complex state management.
* Keep components reusable and simple.
* Mobile-first responsive design.
* Focus on performance and readability.

---

# Design Rules

Style:

* premium dark barbershop aesthetic
* black background
* charcoal sections
* gold accent colors
* white typography

UI:

* strong typography hierarchy
* large hero section
* clean spacing
* modern cards/buttons
* subtle hover effects only
* no excessive animations

---

# SEO Rules

Target location:
Hobart, Tasmania, Australia.

Target keywords:

* barber Hobart
* barbershop Hobart
* men’s haircut Hobart
* fade haircut Hobart
* beard trim Hobart
* Colombian barber Hobart
* Latino barber Hobart

Requirements:

* only one H1
* semantic headings
* metadata optimization
* Open Graph metadata
* LocalBusiness JSON-LD schema
* descriptive image alt text

---

# Booking

# Conversion Goals

Every section should help:

* build trust

* show professionalism
